Dango额度团子

我同时开着好几家 AI 的会员，老是用着用着额度就没了。 所以做了这串团子挂在屏幕边上：一颗是一家，额度多它就笑，快没了就垮脸，查不到干脆哭给你看。

这是它真在桌面上的样子

左边是截图。62pt 宽的一条，不抢焦点，平时基本注意不到它。鼠标放上去才滑出卡片：每个额度还剩多少、多久重置、今天烧了多少 token。

收起来就是一粒

点顶上那道弧，团子一颗颗缩回去，剩一粒小药丸；再点一下又弹出来。放在哪、收没收起来，下次打开还是那样。

Rust 写的原生小件

用 winit 和 Core Animation 直接画，表情球是从 grok-ball 移植过来的。开了省电模式的话平时一动不动，鼠标过去才动。

你用哪家，就挂哪颗

第一次打开，它只挂你电脑上装了的那几家，不会一上来一排哭脸。别的去「添加小球」里点一下。

包月的：登录一下就行

点「登录并添加」，它会调那家自己的登录：有命令行就在终端跑官方命令，没有就打开它的 App。Dango 不经手登录，只读你登录完留下的状态。

Claude App Cursor cursor-agent login Devin devin auth login Factory App

按量付费的：贴个 API Key

贴上 Key，它去那家官方的余额接口查。Key 存在 Mac 钥匙串里，只发给那一家。想要一圈环的话填个预算，按余额占预算来画。

每天示意数据

按模型

读本机记录

Claude Code 和 Factory 读会话日志，Devin 读它自己的会话库。都是只读打开，不会动你的文件。

Cursor 走官方明细

Cursor 的数来自它自己的用量明细，App 和命令行都算，五分钟同步一次，第一次往回补 30 天。

记在付钱的那家头上

一个工具接了好几家模型的话，按当时的配置找到真正扣钱的那个套餐，记到它名下。

它只看，不碰你的账号

登录状态只读

各家 App 的登录状态只读不写，也不会帮你刷新 token，免得把你正在用的 App 挤下线。

Key 只放钥匙串

你贴进来的 token 和 API Key 放在 Mac 钥匙串里 Dango 自己那格，不写文件、不进日志、也不回传给页面。

挂了就说挂了

查不到就哭，顺便告诉你怎么修。不会拿之前的旧数字顶上，也不会瞎编一个百分比。

只连该连的

查额度只找各家自己的接口。本地控制接口只听 127.0.0.1，别的网页发来的请求直接拒掉。

下下来，拖进应用程序就能用

Apple Silicon 的 Mac，macOS 13 以上。免费，代码在 GitHub（MIT）。

下载 Dango 0.1.0 · 4.8 MB 去 GitHub 下 ↗
  1. 解压，把 Dango.app 拖进「应用程序」。
  2. 第一次打开会被系统拦下来：我没交苹果的开发者年费，做不了公证。去「系统设置 → 隐私与安全性」往下拉，点「仍要打开」就好。
  3. 想开机自己启动的话：系统设置 → 通用 → 登录项，把 Dango 加进去。
设置　点程序坞里的 Dango，或菜单栏图标 →「设置…」：排顺序、换形状颜色、加球、看 Token 账。关掉设置，程序坞图标就收起来
有数　想让哪颗球有数，就装上那家的 App 或命令行并登录
源码　github.com/Jules-0409/dango，装好 Rust 以后 cargo build --release。有问题提 issue，想给你常用的那家做颗新球，欢迎发 PR
