实拍就长这样

左边是它在桌面上的真实样子：62pt 宽的一条细胶囊，窗口不抢焦点，平时安静得像不存在。悬停一颗球，旁边滑出详情卡：每个额度窗口的进度条、重置倒计时、今天烧了多少 token。

收起来就是一粒

点底部的把手，整串团子按顺序缩回去，只剩一颗小胶囊；再点一下又一颗颗弹出来。位置和折叠状态都会记住。

原生，不是网页套壳

Rust + winit + Core Animation 直接画，表情球是 grok-ball 引擎的移植版。省电模式下平时完全静止，悬停才动。

Add a ball

你用哪家，就串哪颗

第一次打开时，它只把这台电脑上装了的那几家串上去，不会一上来就是一排哭脸。别的在「添加小球」里点一下就行。

订阅套餐 · 一键登录

点「登录并添加」，调起那家自己的官方登录：有命令行就在终端里跑官方命令，没有就打开它的 App。Dango 自己不碰任何登录流程，只读登录之后留下的状态。

按量付费 · 填 API Key 看余额

贴一个 API Key，它就去那家的官方余额接口查。Key 只存进 macOS 钥匙串，只发给那一家。想要一圈环的话，填个预算，它按余额占预算的比例画。

读本机日志

Claude Code 和 Factory Droid 的用量直接从本机会话日志里读，按消息去重，只读不改。

Cursor 用官方明细

Cursor 的用量来自它自己的用量明细接口，五分钟同步一次，第一次回填 30 天。

认得出是谁付的钱

同一个 Agent 接了好几家模型的时候，按当时的配置找到真正的付费方，按源头也能分开看。

Honest by default

它只看，不动你的账号

凭据只读

各家 App 的登录态只读不写，也从不帮你刷新 token，免得把正在用的 App 挤下线。

密钥只进钥匙串

你粘进来的 token 和 API Key 存在 macOS 钥匙串里 Dango 自己那一格，不落盘、不进日志、不回传给页面。

挂了就说挂了

查不到就哭脸，附一句人话告诉你怎么修。不拿缓存里的旧数字冒充，也不编一个百分比。

只连它该连的

查额度只打各家自己的接口；控制接口只听本机 127.0.0.1，外来网页请求一律拒绝。

# 从源码构建（Rust 1.8x，macOS）
git clone <即将公开> dango
cd dango
cargo build --workspace --release
./target/release/dango
系统　macOS，Apple Silicon 上日常在用
依赖　Rust 工具链；想让哪颗球有数，就装上并登录那家的 App 或命令行
设置　菜单栏里点「设置…」，排顺序、换形状颜色、加小球、看 Token 账
